📊 Education & Student Analytics System

Data Analytics Project | Excel • Power BI

A data analytics project designed to analyze student performance, academic records, and educational data using Microsoft Excel and Power BI.

📌 Project Overview

The Education & Student Analytics System focuses on transforming educational data into meaningful insights. It helps analyze student performance, identify academic trends, and present data through interactive dashboards and visual reports.

🎯 Project Objectives

- Analyze student academic performance.
- Track student records and educational data.
- Identify performance trends and patterns.
- Create meaningful data visualizations.
- Support data-driven educational decisions.

🛠️ Tools & Technologies

- Microsoft Excel – Data cleaning, data organization and analysis.
- Microsoft Power BI – Interactive dashboards and data visualization.

📂 Project Files

- Excel Dataset
- Power BI Dashboard (.pbix)
- Project Report (PDF)
- Dashboard Screenshots

📈 Key Features

- Student Performance Analysis
- Academic Data Analysis
- Data Visualization
- Interactive Dashboard
- Educational Insights

🚀 How to Use

1. Download or clone this repository.
2. Extract the project ZIP file if required.
3. Open the Excel file to explore the dataset and analysis.
4. Open the ".pbix" file using Microsoft Power BI Desktop.
5. Explore the dashboard and visual reports.
